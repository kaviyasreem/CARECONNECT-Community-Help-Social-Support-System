# CARECONNECT-Community-Help-Social-Support-System
CARECONNECT is a community support platform that connects people who need help with volunteers who are willing to provide assistance.

# CARECONNECT ❤️

### Community Help and Social Support System

## Project Overview
CARECONNECT is a social impact application
that connects people who need assistance
with community volunteers.

## Problem Statement
People facing difficulties often struggle
to find local community support.

## Objectives
- Connect people with volunteers.
- Encourage blood donation awareness.
- Organize community help requests.
- Promote social responsibility.

## Features
- Help request registration
- Volunteer registration
- Blood donor registration
- Community dashboard
- Request data export

## Technologies Used
- Python
- Streamlit
- Pandas

## Domain
Social Welfare and Community Development

## Future Enhancements
- Database integration
- Location-based volunteer matching
- SMS notifications
- Admin verification system
